# 1.1 feature list — living GO checklist

This is the working checklist for declaring **Herdr MCP 1.1 stable**. It
condenses what 1.1 ships, how it compares with adjacent tools, and exactly
what remains before a stable GO. Keep every row's status honest: `TODO`,
`PARTIAL`, or `DONE`, each with a one-line acceptance condition. Update this
file as gates close; the tagged release notes stay frozen in
[`v1.1.0.md`](v1.1.0.md).

## 1. Goal and non-goals

Goal: a **three-layer browser capability** for MCP clients —

1. **Chrome extension** — owns tabs, content observation, and page actions in
   the user's real browser.
2. **Local host (Runtime)** — exposes those capabilities to local MCP clients
   with idempotency, delivery states (`applied` / `uncertain` / `not_applied`),
   and per-caller grants.
3. **Site adapters** — optional, reviewed layers on the *same* BrowserPage API
   that turn proven page operations into reliable site operations (Bilibili,
   X, Doubao today; any site via the skill-adapter model).

Non-goals (explicitly **not** 1.1 GO criteria):

- **Full site/command catalog parity with OpenCLI.** OpenCLI ships a very
  large hand-curated site catalog; Herdr ships a small set of reviewed
  adapters plus the authoring model. Parity in breadth is not a gate.
- Unrestricted page eval / arbitrary CDP exposure to model callers (the
  runtime deliberately keeps mutation fenced and observable).
- Social-write automation, cross-frame trees, generic upload/download, and
  hover/drag gestures.

## 2. Architecture (one paragraph + pointer)

MCP clients (local or via Edge/WebChat) call the Runtime; the Runtime fences
every mutation behind caller grants and idempotency, forwards browser
operations to the extension over the trusted native channel; the extension
executes them against owned or claimed tabs and reports postcondition
evidence; the Runtime settles delivery state from that evidence — never from
optimistic success. WebChat (ChatGPT/Grok/Claude sessions) rides the same
extension boundary with per-endpoint control grants instead of a parallel
automation path. Adapters are skills over BrowserPage, not plugins inside a
page VM. Details: [`../_wip/v1.1-browser-adapter-platform.md`](../_wip/v1.1-browser-adapter-platform.md),
[`../_wip/browser-control-plane.md`](../_wip/browser-control-plane.md).

## 3. Condensed capability matrix

Legend: **Y** shipped and usable · **P** partial (limits tracked below) ·
**N** not offered. Comparison targets: [sctl](https://github.com/scriptscat/sctl)
(ScriptCat's CDP/scripting power tool), [OpenCLI](https://github.com/jackwener/opencli)
(CLI + large site catalog), [BrowserMCP](https://github.com/jackwener/BrowserMCP)
(browser automation over MCP — the closest twin).

| Capability | sctl | OpenCLI | BrowserMCP | herdr 1.1 |
|---|---|---|---|---|
| MCP client access to browser ops | N | P (CLI, not MCP grants) | Y | Y |
| Tab lifecycle incl. claiming user tabs | P | Y | Y | Y (owned tabs closed+verified; user tabs claim-only) |
| Raw eval / CDP scripting in page | Y | P (chrome.debugger attach; detectable) | N | N (by design; Store-safe) |
| Curated site adapters | via userscripts | Y (large catalog) | N | P (Bilibili/X/Doubao + skill model) |
| Idempotency + typed delivery states | N | N | N | Y |
| Per-caller scoped grants (WebChat control plane) | N | N | N | Y |
| Multi-provider WebChat sessions (create/send/stop/archive) | N | N | N | Y (ChatGPT primary; Grok/Claude stop) |
| Element refs + observe | P | Y | Y | P (128-element doc-order cap — [#615](https://github.com/whshang/herdr-mcp/issues/615)) |
| Forms: fill/dropdowns/inner scroll | Y | Y | P | Y (incl. >24-option dropdowns, container scroll) |
| Trusted-key press | Y | Y | N | P (`isTrusted=false` limits — [#617](https://github.com/whshang/herdr-mcp/issues/617)) |
| Screenshot capture | Y | Y | Y | Y (bounded, cached artifacts) |

## 5. Should-have (1.1.x acceptable if deferred)

- Generic tab list/activate for MCP callers (today: scoped sessions + claims).
- Nested-scroll UAT beyond the container-scroll cases already covered.
- [#624](https://github.com/whshang/herdr-mcp/issues/624) title projection
  re-apply after the first assistant turn.
- [#623](https://github.com/whshang/herdr-mcp/issues/623) archive without an
  open tab.
- Grant UX polish (extension-side visibility of caller grants).
- Jev/semantic fast-path benchmarks on the GO SHA — numbers only, **no
  blanket speed claim** (route 403 and threshold-calibration follow-ups:
  [#621](https://github.com/whshang/herdr-mcp/issues/621),
  [#622](https://github.com/whshang/herdr-mcp/issues/622)).

## 6. Optimize-later (explicit non-GO)

- OpenCLI-scale site catalog growth.
- Hover/drag gestures, iframes/frames trees, generic upload/download.
- Unrestricted eval or raw CDP for Store callers.
- Social-write automation.

## 7. Known limitations (mirrored from v1.1.0.md)

- `press` synthesizes untrusted key events; browser defaults are not
  guaranteed — prefer explicit click. [#617](https://github.com/whshang/herdr-mcp/issues/617)
- jev-vercel semantic route returns 403 per call. [#621](https://github.com/whshang/herdr-mcp/issues/621)
- Semantic fast-path calibration margin vs fixed threshold contract
  inconsistency. [#622](https://github.com/whshang/herdr-mcp/issues/622)
- Edge/Link `create` beyond ~60s ends in request timeout; retry with the same
  idempotency key (never rotate it).
- Created-session title may be overwritten by ChatGPT auto-title;
  `title_projection` reflects creation-time projection only. [#624](https://github.com/whshang/herdr-mcp/issues/624)
- Archive requires the session tab open, else `browser_session_target_unavailable`. [#623](https://github.com/whshang/herdr-mcp/issues/623)
- `observe` caps at the first 128 elements in document order. [#615](https://github.com/whshang/herdr-mcp/issues/615)
- Post-upgrade `rollback` is macOS-only for the service path; Windows
  x86_64/ARM64 remain Candidate support.
