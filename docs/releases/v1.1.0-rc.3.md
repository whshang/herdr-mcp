# Herdr MCP v1.1.0-rc.3

v1.1.0-rc.3 是 1.1 的第三个预发布，仅面向 **preview** 更新通道。本 RC 在 rc.2 基础上合并 Phase 2 浏览器/prompt 修复、endpoint 在线判定、Linux native host、relay 工作日志，以及 log cursor 与 `work_events` 同事务提交。stable 用户继续留在 1.0.x。

## 升级

已处于 epoch 5 的 v1.1.0-rc.1 / rc.2 用户，在 preview 通道使用 `herdr-mcp update` 升级到 v1.1.0-rc.3。源码 dogfood 机器继续用 `herdr-mcp dev sync`。

从 v1.0.x（epoch 4）出发的路径仍为两步（与 rc.2 相同）：

```text
v1.0.x（epoch 4）
  → v1.0.4 bridge（epoch 4，同一 contract identity）
  → v1.1.0-rc.3（epoch 5，签名清单声明 contract_migration）
```

**浏览器扩展升级顺序：** 若扩展落后于本 Runtime generation，先升级/重载浏览器扩展（或重载 service worker），再切换 Runtime。Runtime 不再把「只轮询 `/push/events`、但未在本 generation 注册」的 endpoint 判为在线。

升级后验证：

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp doctor
```

确认 Runtime 为 1.1.0-rc.3、Runtime contract epoch 5 / 18 tools、state schema 15，service / local MCP 健康且 Link 在线。验证实际 active generation 和受管服务，源码版本与构建产物不能证明生产 Runtime 已升级。

## 主要变更

- **Endpoint 在线判定与 generation 切换恢复：** Runtime 要求本 generation 已注册的 browser endpoint 才判在线；未取走的队列命令在超时后返回可重试 `not_delivered`。扩展在 Runtime generation 切换后重新注册并刷新 push stream。 [#632](https://github.com/whshang/herdr-mcp/issues/632) [PR #633](https://github.com/whshang/herdr-mcp/pull/633)
- **Prompt / session.create 可靠性：** 跨 Runtime 重启围栏 durable task completion；`session.create` 在 reconcile 轮询后重试 late acceptance；ChatGPT Project vanity URL 规范为 canonical source route；`title_projection` 经 session.create reconcile 携带并报告 `classification_reason`。 [PR #639](https://github.com/whshang/herdr-mcp/pull/639) [PR #641](https://github.com/whshang/herdr-mcp/pull/641) [PR #642](https://github.com/whshang/herdr-mcp/pull/642) [PR #628](https://github.com/whshang/herdr-mcp/pull/628)
- **Generic Browser Page：** 通用 interactive refs 与结构化 page assertions（UAT 路径）。 [PR #636](https://github.com/whshang/herdr-mcp/pull/636)
- **Relay：** log cursor 与 `work_events` 在同一 SQLite 事务中推进，避免丢事件后 cursor 已前进；handoff / work journal / work tailers（droid、grok CLI、cursor-agent）MVP。 [PR #655](https://github.com/whshang/herdr-mcp/pull/655) [PR #647](https://github.com/whshang/herdr-mcp/pull/647) [PR #650](https://github.com/whshang/herdr-mcp/pull/650)
- **Linux：** Runtime 提供 Chrome native host；`dev sync` 激活门禁、service rollback 与 Link 在 service start 时恢复。 [PR #643](https://github.com/whshang/herdr-mcp/pull/643) [PR #646](https://github.com/whshang/herdr-mcp/pull/646)
- **Semantic：** background chat tier、per-tier cooldown、max_tokens/JSON mode、usage 与 hourly cap。 [PR #645](https://github.com/whshang/herdr-mcp/pull/645)
- **Page Assist grant migration：** orphans / migrate dry-run / `--confirm` 与 reject audit。 [PR #630](https://github.com/whshang/herdr-mcp/pull/630)

## 已知限制

- 本版本仅供 preview 验证，stable 用户继续使用 1.0.x；正式 v1.1.0 仍需完成 PROD 升级/回滚验收。
- 成功升级后的 `herdr-mcp rollback` 仅限 macOS。Linux 不写入成功后的 service rollback 记录（DEV sync 路径除外的生产声明不变）。
- Browser Extension 独立发布；本 Runtime RC 不发布 Store/Standalone 扩展。
- 未合并：#634（extension recovery gate / silent-drop）、#638（device-scoped WebChat grant 派生权限）、#644（blocked）。

## 兼容性

- Workstation Runtime Execution Contract：epoch **5 / 18 tools**。
- First-party Public Edge contract：epoch **8 / 19 actions**。本 RC **不**部署 Edge。
- Durable Runtime state：schema **15**。
- Runtime 自更新不更新 Browser Extension；升级顺序见上文。
