# Herdr MCP v1.0.1

Herdr MCP v1.0.1 is a stable updater/distribution compatibility patch. Runtime state schema, execution contract, provider scope, and browser-extension version are unchanged from v1.0.0.

## Upgrade from v1.0.0 / v1.0.0-alpha.9

Use the normal stable update command:

```bash
herdr-mcp update
```

v1.0.1 publishes both `runtime-manifest.json` and the attested legacy alias `release-manifest.json`. This restores direct stable discovery for v1.0.0-alpha.9 and other pre-1.0 updaters that only know the legacy manifest filename. Those clients no longer skip the current stable release and fall back to v0.4.9/schema 5.

After upgrade, verify:

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp service status
herdr-mcp link status
herdr-mcp doctor
```

## Main changes

- **Stable releases retain the attested legacy manifest alias.** Runtime release publication now emits byte-identical `runtime-manifest.json` and `release-manifest.json` files for stable as well as prerelease tags, and release recovery requires that alias for post-v1.0.0 runtime-manifest releases while preserving recovery compatibility for the historical v1.0.0 bundle. This fixes alpha.9 stable update discovery without weakening schema, contract, digest, source-identity, or attestation checks. [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

## Known issues

- Windows x86_64 and ARM64 remain **Candidate** support until their separate Production-promotion records are complete.
- Browser-extension DEV / STANDALONE / Chrome Web Store distribution remains versioned independently. The Runtime v1.0.1 patch does not change extension **0.1.133**.
- ChatGPT remains the 1.0 reference provider. Claude and Grok are compatibility providers; Gemini remains outside the stable 1.0 provider scope.

## Compatibility

- Workstation Runtime Execution Contract: epoch **4**, **18 tools**.
- Durable Runtime state: schema **15**.
- First-party DEV/PROD Public Edge contract: epoch **7**, **19 actions**.
- Published Runtime targets remain `aarch64-apple-darwin`, `x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl`, `x86_64-pc-windows-msvc`, and `aarch64-pc-windows-msvc`.
- Existing Worker public origin, enrolled-device identity, OAuth/Connector identity, and rollback boundaries are unchanged.
