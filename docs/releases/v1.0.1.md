# Herdr MCP v1.0.1

v1.0.1 是 1.0 稳定线的安装与恢复补丁，Runtime state schema、执行契约、provider 范围和浏览器扩展版本都不变。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

## 升级

稳定 1.x 使用普通更新命令： [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

```bash
herdr-mcp update
```

1.0 alpha 仅用于内部开发机，不作为公开自动升级兼容目标；维护者可直接把这些开发机手动升级到精确 stable candidate。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

公开 v0.4.8 用户仍沿用冻结链路：`v0.4.8 → v0.4.9 bridge → 当前 stable 1.x`。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

升级后验证： [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp service status
herdr-mcp link status
herdr-mcp doctor
```

## 主要变更

### 1.0 主要变化

- **WebChat / ChatGPT 会话控制与可靠接力。** 1.0 可以创建和打开受支持的 WebChat 会话、派发任务、观察持久化结果、归档任务创建的会话，并沿一条 Continuity 链继续工作；ChatGPT Project 的 fresh-create、cleanup、重试和 App identity 都有明确的 fail-closed / no-blind-replay 语义。 [PR #517](https://github.com/whshang/herdr-mcp/pull/517) [PR #537](https://github.com/whshang/herdr-mcp/pull/537) [PR #538](https://github.com/whshang/herdr-mcp/pull/538)
- **持久化异步 Agent 任务。** Parent 可以一次提交 child work，立即获得稳定 task / dispatch identity，继续自己的工作，并在之后读取 durable terminal / inbox 结果；delivery uncertain 会作为终态证据保留，不会被自动重放。 [PR #530](https://github.com/whshang/herdr-mcp/pull/530)
- **Project-scoped Codex conversation continuity。** Herdr 可以从精确 managed project 目录列出、读取并恢复 Codex session；没有显式 session id 时优先恢复同目录的 live / recent conversation，显式 session identity 仍然优先，内部 reasoning / tool / system 注入内容不会投影到用户历史。 [PR #544](https://github.com/whshang/herdr-mcp/pull/544)
- **Semantic / Jev 辅助但不获得新的执行 authority。** Browser Auto、planner 和 task boundary 可以使用 provider-neutral semantic route pool 做 typed evaluation / chat judgment；权限、delivery、idempotency、account identity、cleanup safety 和验证仍由确定性规则控制，semantic provider 不可用时保持原有行为。 [PR #499](https://github.com/whshang/herdr-mcp/pull/499)
- **模型可见结果中立化与更简单的 planner contract。** Herdr-generated advisory prose 从 model-visible tool metadata 中移除，只保留事实性的 delivery/status 和 caller-owned stdout/stderr；remote-planner Skill 缩小并把高风险 connected-tool 调用形状前置。 [PR #539](https://github.com/whshang/herdr-mcp/pull/539) [PR #540](https://github.com/whshang/herdr-mcp/pull/540) [PR #541](https://github.com/whshang/herdr-mcp/pull/541)
- **多设备路由和更实时的 fleet health。** enrolled workstation 的 device identity 保持显式、fail-closed；Edge 在验证过的 Link reconnect 后立即刷新 Runtime health，避免继续把旧 offline 状态当成当前状态。 [PR #542](https://github.com/whshang/herdr-mcp/pull/542)
- **稳定升级 / rollback 边界。** 1.0 固定 Runtime schema **15**、Execution epoch **4 / 18 tools**、first-party Public Edge epoch **7 / 19 actions**；公开 v0.4.8 用户通过 v0.4.9 bridge 跨越 schema 5 → 15，保留原 v0.4.8 binary/database snapshot 作为 N-1 rollback source，并原地保留 Worker public origin、OAuth、设备和 Connector identity。 [PR #409](https://github.com/whshang/herdr-mcp/pull/409) [PR #417](https://github.com/whshang/herdr-mcp/pull/417) [PR #534](https://github.com/whshang/herdr-mcp/pull/534)
- **五平台发布与明确的平台边界。** Runtime 正式生成 macOS Apple Silicon、Linux x86_64/ARM64 musl、Windows x86_64/ARM64 五个平台 artifact，并发布 Edge bundle、runtime manifest 和 GitHub attestation；macOS Apple Silicon、Linux x86_64、Linux ARM64 为 Production，Windows x86_64/ARM64 仍为 Candidate，WSL 为 Unsupported。 [PR #543](https://github.com/whshang/herdr-mcp/pull/543) [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- **Provider 支持边界在 1.0 冻结。** ChatGPT 是 reference provider；Claude / Grok 提供兼容的 signed-in dispatch/result 路径，但不声明与 ChatGPT 相同的 Planner / automation 能力；Gemini 不在 stable 1.0 范围内。 [PR #543](https://github.com/whshang/herdr-mcp/pull/543)

### 1.0.1 修复

- `herdr-mcp install` 自动修复 Herdr 依赖：依次解析 `HERDR_BIN`、用户稳定安装路径、Homebrew / `/usr/local` 和 PATH；已安装时验证 CLI/API 并尝试稳定更新；完全缺失时调用 herdr.dev 官方安装器。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- 安装流程只有在本机 Herdr Server/API 真正可达后才算完成；macOS 继续由 Supervisor/TCC broker 管理，Linux / Windows 必要时自动启动当前用户的 Herdr Server。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- 修复首次安装后 Herdr Server 未启动，导致找不到窗口 / 无法继续切换本地路径的失败模式；Agent 安装协议改为依赖 `herdr-mcp install` 自修复。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- Runtime / package / Edge 公开版本统一到 **1.0.1**；Browser Extension 继续保持 **0.1.133**。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- stable 1.x 继续只发布 `runtime-manifest.json`，保持 v0.4.8 → v0.4.9 major-upgrade bridge 的选择语义不变。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

## 已知限制

- Windows x86_64 / ARM64 仍属于 Candidate 支持，等待独立的 Production-promotion 实体机验收。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- Browser Extension DEV / STANDALONE / Chrome Web Store 继续独立版本化；本次 Runtime patch 不升级扩展。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- ChatGPT 仍是 1.0 reference provider；Claude / Grok 是兼容 provider；Gemini 不在 1.0 stable 范围内。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

## 兼容性

- Workstation Runtime Execution Contract：epoch **4 / 18 tools**。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- Durable Runtime state：schema **15**。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- First-party DEV/PROD Public Edge contract：epoch **7 / 19 actions**。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- 发布目标继续为 macOS Apple Silicon、Linux x86_64/ARM64 musl、Windows x86_64/ARM64。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- Worker public origin、设备身份、OAuth/Connector identity 和 rollback 边界不变。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
