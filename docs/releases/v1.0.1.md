# Herdr MCP v1.0.1

v1.0.1 是 1.0 稳定线的安装与恢复补丁，Runtime state schema、执行契约、provider 范围和浏览器扩展版本都不变。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

## 升级

稳定 1.x 使用普通更新命令： [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

```bash
herdr-mcp update
```

1.0 alpha 仅用于内部开发机，不作为公开自动升级兼容目标；维护者可直接把这些开发机手动升级到精确 stable candidate。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

公开 v0.4.8 用户仍沿用冻结链路：`v0.4.8 → v0.4.9 bridge → 当前 stable 1.x`。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

升级后验证： [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp service status
herdr-mcp link status
herdr-mcp doctor
```

## 主要变更

- `herdr-mcp install` 自动修复 Herdr 依赖：依次解析 `HERDR_BIN`、用户稳定安装路径、Homebrew / `/usr/local` 和 PATH；已安装时验证 CLI/API 并尝试稳定更新；完全缺失时调用 herdr.dev 官方安装器。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- 安装流程只有在本机 Herdr Server/API 真正可达后才算完成；macOS 继续由 Supervisor/TCC broker 管理，Linux / Windows 必要时自动启动当前用户的 Herdr Server。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- 修复首次安装后 Herdr Server 未启动，导致找不到窗口 / 无法继续切换本地路径的失败模式；Agent 安装协议改为依赖 `herdr-mcp install` 自修复。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- Runtime / package / Edge 公开版本统一到 **1.0.1**；Browser Extension 继续保持 **0.1.133**。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- stable 1.x 继续只发布 `runtime-manifest.json`，保持 v0.4.8 → v0.4.9 major-upgrade bridge 的选择语义不变。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

## 已知限制

- Windows x86_64 / ARM64 仍属于 Candidate 支持，等待独立的 Production-promotion 实体机验收。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- Browser Extension DEV / STANDALONE / Chrome Web Store 继续独立版本化；本次 Runtime patch 不升级扩展。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- ChatGPT 仍是 1.0 reference provider；Claude / Grok 是兼容 provider；Gemini 不在 1.0 stable 范围内。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)

## 兼容性

- Workstation Runtime Execution Contract：epoch **4 / 18 tools**。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- Durable Runtime state：schema **15**。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- First-party DEV/PROD Public Edge contract：epoch **7 / 19 actions**。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- 发布目标继续为 macOS Apple Silicon、Linux x86_64/ARM64 musl、Windows x86_64/ARM64。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
- Worker public origin、设备身份、OAuth/Connector identity 和 rollback 边界不变。 [PR #546](https://github.com/whshang/herdr-mcp/pull/546)
