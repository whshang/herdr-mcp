# Herdr MCP v1.2.1

v1.2.1（2026-11-20）是 1.2 稳定线的首个维护与热路径优化版本，集中合入 `v1.2.0` 发布以来的 28 项修复与性能改进：修复发版清单 `contract_migration.state_schema_from` 在 epoch 5 → 6 同为 schema 16 时的准入描述以打通 `v1.1.1` → `v1.2.1` 直接 `herdr-mcp update`、更新器与扩展下载全路径有界超时、拓扑快照 `Arc` 零拷贝共享、`child_process` 与 `exec.wait` 微退避轮询、会话结束锁外持久化与错误栈保留窗口、`herdr_inspect` 受管根 `git status` 缓存、文件系统与 Git 工具大目录剪枝、Utility pane 按工作区隔离、Semantic 配置与连接复用、Cloudflare Edge DO 设备缓存与原子结算，以及浏览器扩展隐藏标签页轮询挂起与内存回收（扩展版本随此前合入的 `#1043`、`#1044`、`#1066` 升至 **`0.1.254`**，本次定版提交不再额外递增 `extension/manifest.json`）。Durable Runtime state（**schema 16**）、Workstation Runtime Execution Contract（**epoch 6 / 18 tools**）、Public Edge Contract（**epoch 8 / 19 actions**）、macOS TCC broker 兼容修订号（**5**）与 Herdr TUI 固定版本（**0.9.5**）保持不变。

## 升级

已处于 `v1.2.0` 或 `v1.1.1`（同为 state schema 16）的用户可直接执行标准更新命令升级到 `v1.2.1`（版本边界 `v1.2.0` → `v1.2.1` 及 `v1.1.1` → `v1.2.1`，无数据库迁移）：

```bash
herdr-mcp update
```

也可先执行 `herdr-mcp update check` 查看目标版本，再执行 `herdr-mcp update apply` 应用更新；源码开发通道若处于 `dev`，请先切回生产快照或使用受支持的通道切换命令后再执行 `herdr-mcp update`。

- **`v1.1.1`（epoch 5，schema 16）直接升级修复：** `v1.2.0` 的发版清单生成脚本曾将 `contract_migration.state_schema_from` 误写为 `15`，导致 `v1.1.1` 主机执行 `herdr-mcp update` 在 `release_plan` 准入校验处被拒绝；`v1.2.1` 通过 `#1084` 将 `contracts/runtime-exec-v5.json` 与 `v6.json` 的 `state_schema` 对齐为 `16`，生成的 `runtime-manifest.json` 写出 `state_schema_from = 16` 且不携带冗余 `state_schema_migration` 块，`v1.1.1` 主机可直接执行 `herdr-mcp update` 跨 epoch 5 → 6 升级到 `v1.2.1`。
- **浏览器扩展（`0.1.251` → `0.1.254`）：升级后请重载扩展。** `v1.2.0` 之后合入的 `#1043`、`#1044`、`#1066` 已将仓库内扩展版本推进至 **0.1.254**。已安装 Standalone 扩展的工作站在 `herdr-mcp update` 期间会自动将本地暂存目录刷新为 **0.1.254**（保留既有 manifest `key` 与扩展 ID）；升级完成后请在 `chrome://extensions` 对 Herdr MCP 执行重新加载，或等待空闲自动重载，使 `herdr-mcp doctor` 中的扩展状态从 `reload_pending` 收敛为 `current`。
- **Fleet Worker 按需同步升级：** 部署自有 Cloudflare Fleet Worker 的用户在看到 `herdr-mcp update status` 提示 Worker 版本落后时，单独执行 `herdr-mcp worker update`（需本人完成交互式 Cloudflare 授权，原地更新不改变 Worker 域名、OAuth、设备配对与 Connector 身份）。

升级后验证：

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp doctor --local
herdr-mcp update status
```

确认 Runtime 为 `1.2.1`、contract epoch `6` / `18` tools、state schema `16`，service 与 local MCP 健康且 Link 在线；重载扩展后 `doctor` 的 standalone 扩展检查为 `current`。

## 主要变更

### 发布清单准入、更新器超时与 CI 门禁

- **发版清单 `state_schema_from` 修正与跨版本准入门禁（`#1084`）。** 在 `contracts/runtime-exec-v4.json`、`v5.json`、`v6.json` 记录对应冻结版本的 `state_schema`（v4 为 15，v5 与 v6 为 16）；`scripts/build-rust-release-manifest.mjs` 从上一冻结契约读取 `state_schema`，当当前 `SCHEMA_VERSION` 与上一冻结版本同为 16 时输出 `contract_migration.state_schema_from = 16` 且省略 `state_schema_migration` 块，并新增直接调用清单脚本的 `admit_release_contract` 准入单测，修复 `v1.1.1` 主机执行 `herdr-mcp update` 的准入拒绝问题。 [PR #1084](https://github.com/whshang/herdr-mcp/pull/1084)
- **更新器与定时更新调度器外部进程有界超时（`#1049`）。** `update_scheduler.rs` 与 `updater.rs` 中的 `launchctl` 状态探测与启停、服务 `stop`/`start`/`uninstall` 生命周期命令、以及候选二进制 `--version` 探测全部改走 `child_process::run_bounded_output`（5s/10s/30s 超时与 32 KiB 输出上限），防止挂起的 `launchctl` 或候选二进制长期占锁阻塞更新流程。 [PR #1058](https://github.com/whshang/herdr-mcp/pull/1058)
- **Standalone 扩展 GitHub 下载客户端连接与总超时加界（`#1048`）。** 为扩展下载 `reqwest` 客户端配置 10s 连接超时与 60s 总超时，并提供测试注入入口，避免半开 TCP 连接或停滞响应体阻塞 `install` 与更新暂存阶段。 [PR #1054](https://github.com/whshang/herdr-mcp/pull/1054)
- **CI Rust 专属通道分流与 Cloudflare 生产门禁根构建顺序修复（`#1025`）。** Rust 专属 PR 路由至选择性 `rust` Node 门禁并在跨语言契约测试前执行 `npm run build`；`extension` 与 `edge` 通道移除冗余根工程 `tsc`；`.github/workflows/cloudflare-edge.yml` 在 `npm run test:edge` 与 `npm run test:built` 之间显式执行 `npm run build`，确保导入 `dist/*.js` 的根回归测试具备构建产物。 [PR #1028](https://github.com/whshang/herdr-mcp/pull/1028)

### 运行时热路径、子进程与执行会话持久化

- **拓扑快照 `Arc<Value>` 零拷贝共享与工具调用捕获前置短路（`#1061`）。** `CacheState.state` 改为 `Arc<Value>` 并通过 `Arc::make_mut` 实现写时复制；`admitted_tool_output` 每次派发只取一份 `Arc` 快照供 `ToolCallCapture` 与 `herdr_fs_*`、`pane.split`、`herdr_exec`、`work.pickup` 共享；`may_record_tool_call` 对不包含作用域键的调用在脱敏与推导前直接跳过事件捕获。 [PR #1075](https://github.com/whshang/herdr-mcp/pull/1075)
- **Supervisor 稳态零刷盘与分级探测（`#1052`）。** 优化 `herdr_supervisor` 在稳态无变化周期的探测频率与快照写盘策略，消除稳态周期内的重复磁盘刷新。 [PR #1056](https://github.com/whshang/herdr-mcp/pull/1056)
- **`child_process` 热路径微退避轮询与延迟孤儿登记（`#1033`）。** `wait_bounded` 与 `run_bounded_output` 将固定 10ms 睡眠替换为 250us → 500us → 1ms → 2ms → 5ms → 10ms 有界指数微退避；子进程仅在存活超过 25ms 宽限窗后才写入磁盘 `child-process-registry.json`，短命命令不再派生 `/bin/ps` 或争抢孤儿登记表文件锁，长耗时子进程的超时回收与启动清理保证保持不变。 [PR #1050](https://github.com/whshang/herdr-mcp/pull/1050)
- **`exec.wait` 前置有界微退避轮询阶梯（`#1063`）。** 将 `exec.wait` 固定 200ms 轮询替换为 10/20/50/100/200ms 阶梯（上限 200ms 并按剩余超时截断），使数百毫秒内结束的短会话在早期步长立即返回。 [PR #1072](https://github.com/whshang/herdr-mcp/pull/1072)
- **会话结束路径 spool 去重、锁外持久化与常驻集淘汰前证据钉死（`#1010-1b`）。** `complete_session` 在状态锁内仅提交 `closed` 状态转换，将 `.spool` 原子落盘与 SQLite settle 移出状态互斥锁并按「先 `.spool`、后 SQLite settle」顺序执行，对瞬态锁冲突做 3 次有界退避；已关闭会话在两项持久化均完成前钉在常驻集内，防止被 `RECOVERY_MAX_ENTRIES` 淘汰或将未完成落盘的行误报为空输出（`session_evidence_incomplete`）。 [PR #1021](https://github.com/whshang/herdr-mcp/pull/1021), [PR #1051](https://github.com/whshang/herdr-mcp/pull/1051)
- **`exec_compact` 压缩阈值调高与中间段错误栈窗口保留（`#1010-1c`）。** 将输出压缩阈值从 8 KiB / 80 行提升至 32 KiB / 200 行，首尾保留预算从 20/40 行提升至 40/120 行；当被省略的中间段命中 Rust `panicked at` / `stack backtrace:`、Python `Traceback (most recent call last):`、JS/TS `Error:` 栈帧或 Rust `error[E…]` 编译诊断时，额外保留关键错误栈窗口（每侧 24 行，单窗上限 160 行）。 [PR #1022](https://github.com/whshang/herdr-mcp/pull/1022)

### 文件系统、Git 状态缓存、任务编排与 Semantic 服务

- **`herdr_inspect` 受管根 `git status` 缓存、singleflight 合并与写路径即时失效（`#1010-1a`、`#1023`）。** 为受管根 `git status` 增加 250ms TTL 缓存与按路径隔离的 singleflight 并发合并；在 `herdr_exec`、`herdr_fs_write`、`herdr_fs_edit`、`text.write` 及 patch 提交成功后立即失效对应上下游受管根缓存；探测等待采用有界 `wait_timeout` 与 RAII 清理并在探测异常中止时由等待方接管，防止卡死标记永久阻塞后续探测。 [PR #1020](https://github.com/whshang/herdr-mcp/pull/1020), [PR #1060](https://github.com/whshang/herdr-mcp/pull/1060)
- **递归 `herdr_fs_list` 默认折叠重型构建产物目录（`#1070`）。** `walk_list` 默认在结果中保留 `target`、`node_modules`、`dist`、`.next`、`build` 目录条目本身但不递归展开其内部文件，避免数万条构建产物耗尽 `max_entries` 预算并挤占源码目录；当调用方 glob 显式匹配该目录名或起始路径已位于该目录内部时仍完整展开。 [PR #1073](https://github.com/whshang/herdr-mcp/pull/1073)
- **无路径过滤的 `herdr_git` diff/status 收敛未跟踪目录枚举（`#1071`）。** 未指定显式 `paths` 过滤时，`herdr_git` diff/status 改用 `--untracked-files=normal` 将整棵未跟踪目录折叠为单条目录项；携带显式 `paths` 过滤时保持 `--untracked-files=all`。 [PR #1078](https://github.com/whshang/herdr-mcp/pull/1078)
- **`herdr_fs_grep` 单文件字节预算提升与跳过大文件计数回传（`#995`）。** 默认单文件扫描上限从 256 KiB 提至 2 MiB、最大上限从 1 MiB 提至 8 MiB；在成功与 `grep_incomplete` 响应中按文件路径去重回传 `skipped_large_files` 计数；macOS linked worktree（`.git` 为文件）改用禁止跨目录 Git 发现的受限参数集调用 `rg`。 [PR #1017](https://github.com/whshang/herdr-mcp/pull/1017)
- **准入配置按文件指纹缓存解析与 continuity 存储移出异步 worker（`#1038`）。** `verify_admitted_backend_config` 按配置文件 `(modified, len)`（Unix 含 `dev/ino/ctime`）指纹缓存解析结果，近期写入、解析失败或文件缺失时始终重读；`post_extension_continuity_turn` 与 `resolve` 的 `state_store` 临界区改由 `tokio::task::spawn_blocking` 执行。 [PR #1045](https://github.com/whshang/herdr-mcp/pull/1045)
- **Utility pane 提交锁按工作区隔离与自持会话有界等待（`#1032`）。** 将 utility pane 提交锁按解析后的 workspace ID 隔离并在提交到达时回收空闲锁桶；当目标 pane 持有登记在册的内部会话时，按请求超时的一半在 2–8s 范围内有界等待前序会话结束，外来忙碌 pane 仍立即拒绝。 [PR #1042](https://github.com/whshang/herdr-mcp/pull/1042)
- **`agent.task.status` 按 `target` 查询、`agent.task.ack` 批量作用域确认与已关闭工作区升级信号过滤（`#1005`）。** `agent.task.status` 支持单传 `{"target": "<pane_or_agent>"}` 返回当前占用或最近终态任务摘要，并按调用方 `parent_session_ref` 强制隔离；`agent.task.ack` 新增 `workspace_id`、`target`、`before_ms` 选择器并无界扫描未确认终态账本实现单次批量确认；`agent.task.inbox` 的 `escalation.signals` 过滤已不在实时快照中的已关闭 workspace/pane。 [PR #1018](https://github.com/whshang/herdr-mcp/pull/1018)
- **Semantic 配置单次装载、进程级 HTTP 客户端复用与后台路由健康度暴露（`#1006`）。** 单次装载 semantic 配置并复用进程级 HTTP client，将 Edge 能力探测移至后台异步刷新；`capability_json` 的 `chat_routes` 新增暴露 `background_consecutive_failures`、`background_cooldown_remaining_ms` 与 `cooldown_remaining_ms`，并将 `SemanticTier::Background` 超时预算从 60s/120s 收紧至 10s/30s。 [PR #1057](https://github.com/whshang/herdr-mcp/pull/1057), [PR #1015](https://github.com/whshang/herdr-mcp/pull/1015)

### Cloudflare Edge、Link 心跳余量、浏览器扩展与设计文档

- **Edge `DeviceRegistryDO` 设备目录内存缓存与事务删除分块（`#1053`）。** 在 DO 生命周期内按存储键后缀水化 `device:` 内存映射以服务 `list`/`get`/`authenticate`/`rename`/`revoke` 读取，事务提交后原地更新并在回滚或写代次竞争时丢弃缓存；将配对消费清理与幂等记录清理的 `tx.delete` 拆分为 `<=128` 键批次以符合 Workers 存储契约。 [PR #1059](https://github.com/whshang/herdr-mcp/pull/1059)
- **Edge `WorkstationDO` 结算阶段 `completed` 与 `idem` 单次原子写入（`#1026`）。** 正常结算与淘汰结算通过单次多键 `storage.put` 原子写入 `completed:<id>` 与 `idem:<key>` 后再删除 `pending:<id>`，保证批量写入失败时 `pending` 记录完整可恢复。 [PR #1029](https://github.com/whshang/herdr-mcp/pull/1029)
- **Edge 状态回复间隔预留 5s 抖动余量（`#1034`）。** 将 `EDGE_STATUS_REPLY_INTERVAL_MS` 从 30000ms 调整为 25000ms，使略早到达的 30s Link 心跳仍能收到状态回复，避免 Link 侧观测到的应用层静默跨过 60s 逼近 90s watchdog。 [PR #1041](https://github.com/whshang/herdr-mcp/pull/1041)
- **浏览器扩展隐藏空闲标签页挂起轮询、手动模式可达性缓存与旧会话状态回收（`#1039`、`#1036`、`#1037`）。** 隐藏且无在途派发的 WebChat 标签页自动挂起 `wake.js` 的 1s 路由轮询与 800ms 回合轮询，在标签页可见、路由变更或收到运行时消息时立即恢复（`#1043`，扩展升至 `0.1.252`）；手动模式下 `h2w_automation_state` 复用驻留 `/push/events` 流或 30s 内的 `/push/state` 可达性结果，并在标签页关闭或会话解绑时回收每标签页映射与陈旧 nudge 状态（`#1044`，扩展升至 `0.1.253`）；Project `active_conv_key` 原地切换时按新绑定的全量会话引用回收旧会话 nudge 状态（`#1066`，扩展升至 `0.1.254`）。 [PR #1043](https://github.com/whshang/herdr-mcp/pull/1043), [PR #1044](https://github.com/whshang/herdr-mcp/pull/1044), [PR #1066](https://github.com/whshang/herdr-mcp/pull/1066)
- **macOS `tcc_broker` 执行中介设计文档（`#1008`）。** 新增 `docs/design/tcc-broker-exec-mediation.md`，定义威胁模型、调用方身份、受管根白名单、参数与环境变量净化、超时回收、审计日志与延迟基线。 [PR #1019](https://github.com/whshang/herdr-mcp/pull/1019)
