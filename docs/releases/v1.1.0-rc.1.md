# Herdr MCP v1.1.0-rc.1

v1.1.0-rc.1 是 1.1 Browser Adapter Platform 的第一个预发布（Release Candidate）。它只发布到 **preview** 更新通道；stable 通道的 `herdr-mcp update` 只选择不带预发布标识的版本，因此 v1.0.x 稳定用户不会自动收到本版本。正式 v1.1.0 将在 MacBook Pro PROD 升级/回滚 UAT 完成后发布。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)

## 升级

仅限主动参与预发布验证的 preview 通道用户（v1.0.3 或更早的 1.0.x 稳定用户保持不变）：

```bash
herdr-mcp update
```

- 从 v1.0.3（或其他 1.0.x）升级到 v1.1.0-rc.1 是同 schema 的 verified update，不需要 major migration、重新 pair device 或重新添加 Connector。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
- stable 通道用户运行同一命令仍停留在 v1.0.3。 [PR #567](https://github.com/whshang/herdr-mcp/pull/567)

升级后验证：

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp doctor
```

成功后应看到 1.1.0-rc.1、schema 15、健康的 service / local MCP，且 Link 在线。

## 主要变更

### Browser Adapter Platform

- 新增 1.1 通用网页控制内核：BrowserPage open/claim/observe/click/fill/expect/screenshot/release/finalize，由 Runtime 统一负责幂等与投递状态；Herdr 打开的标签页在 finalize 时关闭并验证，用户已有标签页只被 claim 不会被关闭。 [PR #570](https://github.com/whshang/herdr-mcp/pull/570), [PR #573](https://github.com/whshang/herdr-mcp/pull/573), [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
- 新增经过审查的参考 Adapter：Bilibili 字幕读取、X 搜索/线程读取、豆包图像生成（提交一次 + 状态对账）。 [PR #574](https://github.com/whshang/herdr-mcp/pull/574), [PR #575](https://github.com/whshang/herdr-mcp/pull/575), [PR #576](https://github.com/whshang/herdr-mcp/pull/576)
- 项目 Skill 形式的浏览器 Adapter 模型与实时生命周期验证；可选 Jev fast-path 进度校准。 [PR #577](https://github.com/whshang/herdr-mcp/pull/577), [PR #578](https://github.com/whshang/herdr-mcp/pull/578), [PR #571](https://github.com/whshang/herdr-mcp/pull/571)
- OpenCLI 风格的表单控件（含超过 24 个选项的下拉框与容器内滚动）和可见元素等待。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)

### WebChat 控制

- WebChat 控制授权改为按 endpoint + provider 计算，支持 `*` 通配；声明 `webchat_control.any_provider` 的 Runtime 可由 Page Assist 授权推导出全部 provider 的控制授权，Edge 对所有页面类方法转发 Page Assist 调用方授权。 [PR #589](https://github.com/whshang/herdr-mcp/pull/589), [PR #595](https://github.com/whshang/herdr-mcp/pull/595)
- ChatGPT 所有路径只提交一次（移除 Enter 兜底），JS/Rust 投递摘要一致，归档不再回退到旧会话绑定，App 候选限定在输入框且精确匹配；Grok/Claude 的 `browser_dispatch.stop` 可定位到目标会话。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
- ChatGPT App 激活、显示名称投影到会话标题、严格的来源 URL 查找。 [PR #583](https://github.com/whshang/herdr-mcp/pull/583), [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
- Edge relay 重放缓存按 Connector 与完整请求限定，记录不完整时 fail closed。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)

### 工作站与工具

- `herdr_exec` 可选持久幂等键；19 个公开工具描述澄清并保留通用回退。 [PR #582](https://github.com/whshang/herdr-mcp/pull/582), [PR #588](https://github.com/whshang/herdr-mcp/pull/588)
- 将仍有效的旧版升级修复移植到当前主线；updater 发布计划发现与信任逻辑独立成模块。 [PR #579](https://github.com/whshang/herdr-mcp/pull/579), [PR #567](https://github.com/whshang/herdr-mcp/pull/567)

## 已知限制

- 这是预发布：MacBook Pro PROD 升级/回滚 UAT 尚未完成，正式 v1.1.0 在其通过后发布。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
- Browser Extension 独立版本化，本 Runtime 预发布不发布 Store/Standalone 扩展；1.1 浏览器功能需要源码 DEV 扩展 0.1.198 或之后的扩展发布。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
- ChatGPT 归档后，由会话流程打开的对话标签页在个别情况下可能残留，需要手动关闭。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
- Windows x86_64 / ARM64 仍属于 Candidate 支持。

## 兼容性

- Workstation Runtime Execution Contract：epoch **5 / 18 tools**（v1.0.3 为 epoch 4）。 [PR #588](https://github.com/whshang/herdr-mcp/pull/588)
- First-party Public Edge contract：epoch **8 / 19 actions**，已部署到 PROD Edge。 [PR #588](https://github.com/whshang/herdr-mcp/pull/588)
- Durable Runtime state：schema **15**，与 v1.0.x 相同。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
- WebChat `provider=*` 授权只发送给声明 `webchat_control.any_provider` 的 Runtime；旧 Runtime 继续收到按 provider 的授权。 [PR #595](https://github.com/whshang/herdr-mcp/pull/595)
- 发布目标继续为 macOS Apple Silicon、Linux x86_64/ARM64 musl、Windows x86_64/ARM64。 [PR #601](https://github.com/whshang/herdr-mcp/pull/601)
