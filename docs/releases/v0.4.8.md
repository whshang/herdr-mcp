# Herdr MCP v0.4.8

v0.4.8 是 0.4.x 的稳定维护基线，重点完善 ChatGPT Connector 授权、Runtime 可靠性、Linux 原生运行路径和发布验证。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)

## 从旧版升级

v0.4.6 / v0.4.7 已撤回，不作为稳定升级基线；已有 v0.4.5 或曾安装候选版的机器都使用普通更新流程。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)

```bash
herdr-mcp update check
herdr-mcp update
```

更新会保留本机配置和已注册设备身份，不需要因为 Runtime 版本变化而重新配对。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)

升级后验证： [PR #344](https://github.com/whshang/herdr-mcp/pull/344)

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp service status
herdr-mcp link status
```

## 主要变更

- ChatGPT Connector 授权改为请求级隔离：新的 state / PKCE 请求必须独立审批，避免不同账号或新连接复用旧审批。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- 修复审批完成后的轮询与返回 ChatGPT 流程，保留明确的 Continue to ChatGPT 回退入口。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- Connector revoke 收敛为实例级撤销，客户端级全量撤销仍保留显式命令；刷新/访问凭据按逻辑 Connector 隔离回收。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- OAuth 增加 RFC 7009 `/oauth/revoke`，并保持服务端撤销证据与 ChatGPT 客户端 Disconnect 行为解耦。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- Connector inventory 增加稳定名称、授权时间、真实 MCP 使用时间和 30 天无活动实例清理。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- `herdr_git diff` 安全展示受限的未跟踪文件元数据；敏感路径、二进制、大文件和截断输出继续 fail-closed。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- `doctor` 分离 service、local MCP auth、remote MCP auth，不再把匿名探针误认为真实 Connector 已就绪。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- Herdr schema 发现支持受管 `~/.local/bin/herdr` 等固定安装位置，避免最小 PATH 的 Linux 服务误报 Herdr 不可用。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- Linux service / Link generation control 收敛到原生 runtime-control/runtime-status 文件，避免旧 macOS sibling 状态干扰。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- Linux 补齐 x86_64 musl 发布物、systemd --user / user-process fallback、私有设备凭据、worker/connect/update 等平台能力。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- CI / Release qualification 增加 Rust sccache、精确 source identity、目标 artifact、attestation 和真实 Linux 安装验证。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)

## 已知限制

- ChatGPT Disconnect 不是可靠的 OAuth revoke 信号，服务端仍以实例级 revoke 和 30 天 inactive GC 为准。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- Windows 在该版本尚不属于完整 0.4.x → 1.x major migration 路径。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)

## 兼容性

- Workstation Runtime Execution Contract：epoch **2 / 18 tools**。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- Public Edge contract：epoch **3 / 19 actions**。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- Durable state：schema **5**。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
- 设备注册和 Connector 授权继续是两个独立控制面。 [PR #344](https://github.com/whshang/herdr-mcp/pull/344)
