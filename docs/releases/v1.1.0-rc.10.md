# Herdr MCP v1.1.0-rc.10

v1.1.0-rc.10 是 1.1 的第十个预发布，仅面向 **preview** 更新通道。相对 rc.9，它合入 TCC Documents 探测边界与 update ok 运行时范围修复、派发幂等结算、doctor 对多 Chromium 浏览器 standalone 扩展探测、设备级 WebChat grants（Edge PROD）、语义路由默认池清理，并把 CI / release gate 的 Herdr TUI 固定版本从 `0.8.2` 升到 `0.9.5`（[#766](https://github.com/whshang/herdr-mcp/issues/766)）。这是**预发布**，stable 用户继续留在 1.0.x；正式 v1.1.0 GA 标签需 owner 另行批准。

## 升级

已处于 schema 16 的 v1.1.0-rc.6 / v1.1.0-rc.7 / v1.1.0-rc.8 / v1.1.0-rc.9 用户，在 preview 通道前台执行 `herdr-mcp update` 升级到 v1.1.0-rc.10（本版本没有新的 state 迁移）。源码 dogfood 机器继续用 `herdr-mcp dev sync`。

v1.1.0-rc.1 – rc.5（schema 15）的 updater 不接纳 schema 迁移，需按 [安装文档](../i18n/zh-CN/install.md) 第 1 步用已验证二进制的 `install` 命令手动安装（与 rc.5 → rc.6 相同）。

从 v1.0.x（epoch 4）出发的路径为 v1.0.4 → v1.0.5 → v1.1.0：

```text
v1.0.x（epoch 4，含 v1.0.4）
  → v1.0.5 bridge（epoch 4，stable 通道，同一 contract identity；updater 接纳 schema 15 → 16）
  → v1.1.0（epoch 5，签名清单声明 contract_migration 与 state_schema_from 15）
```

v1.0.4 的 updater 只接纳与本机相同的 state schema，无法直接升级到 schema 16，必须先通过 stable 通道的 `herdr-mcp update` 到达 [v1.0.5](https://github.com/whshang/herdr-mcp/releases/tag/v1.0.5)。正式 v1.1.0 发布前，本 RC 仅用于 preview 验证。

**浏览器扩展升级顺序：** 扩展仍为 **0.1.229**（本版本无扩展变更）。先确认扩展为 0.1.229（或更新），再切换 Runtime。Runtime 自更新不会更新扩展。

**⚠️ 状态库迁移不可降级：** 从 schema 15 首次启动 rc.10 会迁移到 schema **16**（rc.6 引入，rc.7–rc.10 无新迁移）；迁移后 rc.5 及更早的二进制（含 v1.0.x）拒绝打开该数据库。升级前请备份 Runtime state 目录；回退到 schema 15 版本必须先恢复迁移前的 state 备份。

**Worker 更新是独立步骤：** `herdr-mcp update` / `update apply` / `update auto` 只更新 Runtime。Worker 落后时保留成功的 Runtime 结果并输出非致命提示，下一步是单独执行 `herdr-mcp worker update`（需要交互式 Cloudflare 授权）；更新过程本身不会启动 Worker 更新、wrangler、设备授权或浏览器。

**macOS TCC 提示：** 升级后若首次访问 `~/Documents`/`~/Desktop`/`~/Downloads`，可能弹出一次性授权窗口；rc.10 已避免归类路径在探测时挂起整条控制链路，但弹窗仍需人工点一次。详见三语 `runtime-self-upgrade` 文档。

升级后验证：

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp doctor
```

确认 Runtime 为 1.1.0-rc.10、Runtime contract epoch 5 / 18 tools、state schema 16，service / local MCP 健康且 Link 在线。验证实际 active generation 和受管服务，源码版本与构建产物不能证明生产 Runtime 已升级。

## 主要变更

- **macOS 受保护目录归类不再触发 TCC 挂起，且 update ok 仅反映 Runtime（#800）：** 受保护目录判定改为纯词法比较，隐式路径跳过受保护目录；`update apply`/`queued` 增加非致命 `macos_documents_tcc_prompt` 提示；`update status` 的 `ok`/`runtime_outcome` 只反映 Runtime。 [PR #802](https://github.com/whshang/herdr-mcp/pull/802)
- **派发幂等：pre-pane 委派拒绝不再留下悬空 reservation（#784）：** `spawn` 派发在创建 pane 前被委派守卫拒绝时，现在持久化拒绝结果并释放 idempotency reservation，同一 key 在 TTL 内重放返回同一拒绝。 [PR #803](https://github.com/whshang/herdr-mcp/pull/803)
- **doctor 在 ego lite 等 Chromium 浏览器中识别 standalone 扩展（#758）：** 按固定顺序扫描多 Chromium user-data 根，避免健康的 ego lite 加载被读成 `not_loaded`/`chrome_not_found`。 [PR #804](https://github.com/whshang/herdr-mcp/pull/804)
- **设备级 WebChat grants、connector 标签与 grant 清理（#713）：** Edge 侧支持 device-wide WebChat grants（从 #666 拆出），PROD Edge 已随该 PR 部署。 [PR #713](https://github.com/whshang/herdr-mcp/pull/713)
- **默认语义路由池去掉 jev-vercel（#621）：** 文档与默认配置改为 decision-vercel 可选接入，避免 Vercel free tier 403。 [PR #805](https://github.com/whshang/herdr-mcp/pull/805)
- **发布说明与 gate 状态对齐（docs）：** 核对 v1.1.0 gate 与 rc.9 风险说明。 [PR #801](https://github.com/whshang/herdr-mcp/pull/801)
- **日常提交回顾 2026-11-01（docs）：** 折叠 #790 与 acceptance-trio 观察。 [PR #799](https://github.com/whshang/herdr-mcp/pull/799)

## 已知限制

- 本版本是预发布，仅供 preview 验证，stable 用户继续使用 1.0.x；正式 v1.1.0 仍需完成 MacBook Pro PROD 升级/回滚验收（#728），且 GA 标签需 owner 另行批准。
- Runtime 更新不再执行 Worker 更新；Worker 落后时只报告 `worker_update_required` 提示，必须由操作员单独执行 `herdr-mcp worker update`（该步骤需要交互式授权）。
- doctor 的 WebChat grant 状态仍只基于本地证据（Edge 没有可读的 grant 列表接口），`absent_locally` 不代表 Edge 侧一定没有 grant。
- schema 16 迁移后 rc.5 及更早的二进制无法打开 state；回退需先恢复迁移前的 state 备份。
- 跨设备来源轮次绑定（chat 在 A 设备、派发到 B 设备）仍不支持，只给出明确的 `caller_browser_on_other_device` 原因（#775）；完整的 late-binding 推迟到 1.1.x（#771）。
- 成功升级后的 `herdr-mcp rollback` 仅限 macOS。
- 设备重新注册后旧 device id 的过期 browser endpoint 仍可能导致 `browser_canonical_url_ambiguous`（1.1.x，#734）。
- Browser Extension 独立发布；本 Runtime RC 不发布 Store/Standalone 扩展。
- 升级 MacBook Pro 时仍可能遇到一次性 Documents TCC 弹窗；处理弹窗前部分控制请求可能短暂受影响，详见 #800/#802。

## 兼容性

- Workstation Runtime Execution Contract：epoch **5 / 18 tools**（`contracts/` 未修改）。
- First-party Public Edge contract：epoch **8 / 19 actions**。发版 PR 改变 Edge 报告的 MCP server 版本字符串，并随 #713 已部署的 device-wide grants 行为一并存在于 PROD。
- Durable Runtime state：schema **16**（rc.10 无新迁移）。
- 浏览器扩展：0.1.229。Runtime 自更新不更新 Browser Extension。
- CI / release gate 固定 Herdr TUI：**0.9.5**（#766）。
