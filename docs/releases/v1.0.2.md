# Herdr MCP v1.0.2

v1.0.2 是 1.0 稳定线的 major-upgrade hotfix，修复旧版 schema 5 Runtime 经 v0.4.9 migration bridge 升级到 1.0.x 时，核心 Runtime 已成功提交后仍可能因为 Herdr Server readiness 收敛失败而被错误判定为整次升级失败的问题。Runtime state schema、执行契约、Edge contract、provider 范围和 Browser Extension 版本均不变。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)

## 升级

所有受支持的旧版本继续只使用标准命令：

```bash
herdr-mcp update
```

- v0.4.3 / v0.4.8 等 schema 5 安装不需要逐版本升级；updater 会先进入 v0.4.9 migration bridge，再选择当前 stable v1.0.2 Runtime。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
- 已安装 v1.0.0 / v1.0.1 的用户走正常同 schema verified update。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
- 不需要手工下载 Runtime、不需要手工运行 `update major-apply`、不需要重新 pair device、重建 Worker 或重新添加 ChatGPT Connector。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)

升级后验证：

```bash
herdr-mcp version
herdr-mcp status
herdr-mcp doctor
```

对于从 0.4.x 升级的机器，成功后应看到 v1.0.2、schema 15、健康的 service / local MCP；此前失败的 update job 可保留为历史证据，新一次成功 job 会记录本次升级结果。

## 主要变更

- 修复 v0.4.x → v1.0.x major migration 的错误回滚：当 Runtime generation、schema migration、service activation、Link 与 native-host 已成功提交，仅剩 Herdr Server readiness 暂未完成时，major migration 保留已提交的新 Runtime并报告可恢复警告，不再错误恢复到 schema 5。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
- 普通 `herdr-mcp install` 的严格门禁不变：安装仍要求 Herdr Server/API ready 才算成功；其他 schema、backup、service、Link、native-host 或 rollback 失败仍然 fail-closed。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
- 0.4.3 与 0.4.8 均确认使用 schema 5，因此都可以直接通过标准 `herdr-mcp update` 进入同一条 v0.4.9 bridge 升级路径，不需要人工先升级到 0.4.8。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)

## 已知限制

- Windows x86_64 / ARM64 仍属于 Candidate 支持；本次 hotfix 不改变平台支持等级。
- Browser Extension DEV / STANDALONE / Chrome Web Store 继续独立版本化；本次 Runtime patch 不升级扩展，仍为 **0.1.133**。
- ChatGPT 继续是 1.0 reference provider；Claude / Grok 是兼容 provider；Gemini 不在 stable 1.0 范围内。

## 兼容性

- Workstation Runtime Execution Contract：epoch **4 / 18 tools**。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
- Durable Runtime state：schema **15**。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
- First-party DEV/PROD Public Edge contract：epoch **7 / 19 actions**。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
- 发布目标继续为 macOS Apple Silicon、Linux x86_64/ARM64 musl、Windows x86_64/ARM64。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
- Worker public origin、设备身份、OAuth/Connector identity、rollback material 与 v0.4.9 migration bridge 选择语义保持不变。 [PR #554](https://github.com/whshang/herdr-mcp/pull/554)
