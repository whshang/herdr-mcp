- **Workstation MCP 契约**: Public contract epoch 2，包含 18 个核心工具，哈希一致。
- **Edge Public 契约**: Public contract epoch 3，包含 19 个公开展现操作/工具，哈希一致。

- **权限与隔离边界**:
  - OAuth Owner / Fleet-admin / Operator 边界严密，已批准 Connector 无法自提权或传递管理其他连接器；
  - 自动化凭据必须绑定单一设备，无法横向越权访问其他设备；
  - WebChat Control 权限仅允许拥有者设备配置；
  - 代际隔离与调用者授权栅栏（Predispatch Generation Fence）在受信任 IPC 上全闭环执行。
