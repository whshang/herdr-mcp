# v0.4.2 local skill registry — 2026-08-30

## Scope decision

v0.4.2 freezes the public epoch-2 MCP catalog at 18 tools and keeps progressive
skills opt-in (`HERDR_MCP_PROGRESSIVE_SKILLS`). This slice adds a **local skill
registry** to the existing `ProgressiveSkillService` so that Web planners can
deterministically discover and read project-local and user-local skills without
new public MCP tools and without network distribution.

The public contract is unchanged: discovery and reads ride through the existing
`herdr_mcp.skill.list` / `herdr_mcp.skill.describe` / `herdr_mcp.skill.load`
local namespace (exposed via `herdr_call`), which already dispatches locally and
fails closed instead of forwarding to Herdr. There is no SkillHub distribution,
no arbitrary home scanning, and no nineteenth MCP tool.

## Precedence and scope (frozen)

- **herdr-mcp built-in / upstream Herdr usage remains highest priority.** A
  project or user skill with the same slug as a builtin module (e.g.
  `files-search`) is dropped, never overriding builtin guidance.
- Below builtins, frozen precedence: **project** `<project_root>/.agents/skills`
  then `<project_root>/.claude/skills`, then **user** `~/.agents/skills` then
  `~/.claude/skills`. A same-name lower-precedence skill never overrides a
  higher-precedence one; the first occurrence for a given skill id wins.
- Both `SKILL.md` and `skill.md` filenames are accepted.

## Determinism and bounded progressive disclosure

- Discovery returns **metadata only** (`id`, `name`, `description`,
  `source_identity`, `uri`, `digest`, `version`, `size`); `load` returns the body
  on demand and is cache-keyed by `(source_identity, uri, digest)`.
- An optional `project_root` param on `list`/`describe`/`load` makes project
  skills resolve deterministically; omitted `project_root` skips project scope.
- Frontmatter is parsed enough for real `~/.agents/skills` skills (name /
  description / summary / version, including `metadata.version` and folded `>`
  scalars) — `ego-browser` and `opencli-usage` parse correctly.
- Local external skills get `project:<root>` / `user:<home>` source identities
  and `skill://local/<id>` URIs with a SHA-256 digest over the trimmed body.

## Confinement (no arbitrary home scanning)

- Candidate dirs are canonicalized; a child or `SKILL.md` symlink that resolves
  outside its `.agents/skills` base is rejected.
- Per-scope count cap and a per-file 512 KiB size ceiling bound discovery.
- `load` re-verifies the digest of the exact bytes it serves and reads within
  the same size bound, so a later oversized file cannot be served.

## Validation

Targeted Rust tests live in `crates/herdr-mcp/src/progressive_skills.rs` and
`crates/herdr-mcp/src/local_skills.rs`:

- precedence (builtin > project > user) and same-name shadowing;
- builtin id shadowed by a user skill is dropped;
- missing `.agents/skills` dirs discover nothing extra;
- metadata-only discovery + body-on-demand load + immutable cache hit;
- symlink escape rejection (list and load fail closed);
- external identity/digest (source identity, URI, version, digest stability);
- size-bound enforcement;
- `project_root` parser validation;
- real-skill frontmatter parsing.

Gate: `cargo fmt --check`, `cargo clippy --workspace --all-targets --all-features -- -D warnings`, and `cargo test -p herdr-mcp` all pass (576 unit tests). Epoch-2 18-tool contract hash is unchanged.
