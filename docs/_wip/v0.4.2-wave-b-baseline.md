## Current-version Progressive Skills candidate

A read-only candidate MCP was started on an isolated config/state directory with `HERDR_MCP_PROGRESSIVE_SKILLS=1`, `HERDR_SKILL_NETWORK=0`, and the real Herdr socket. The candidate was terminated afterward and its `/tmp` state was removed.

| Response | MCP tool text bytes |
| --- | ---: |
| progressive bootstrap | 5724 |
| legacy full (`legacy_full=true`, native reference disabled) | 23493 |
| `files-search` load | 1537 |
| `execution` load | 1594 |
| `workstation-control + agent-dispatch` load | 3891 |
| five-skill development load | 9138 |

Compared with the 23,493-byte legacy response, bootstrap + first domain load is about 69.1% smaller for filesystem work, 68.9% for execution, 59.1% for Agent delegation, and 36.7% for the five-skill development profile. Repeated loads reported cache hits and retained effectively identical response size/order.

The payload result remains favorable, but default-on is blocked by public-contract compatibility: frozen epoch-2 `herdr_skill` exposes only `refresh` and `include_native_reference` and describes the legacy full dynamic-skill semantics. `legacy_full` exists only as an internal runtime argument and is absent from the public schema. Default-on would therefore change the default public response shape without a published per-call compatibility escape hatch, or require changing the frozen contract/hash.

## Interpretation contract

- Direct filesystem/Git/search measurements are deterministic workstation costs and may be used for hard regression thresholds.
- `scan --json` measures cached inventory access; `scan --json --probe` measures explicit capability refresh and must not be put on every request path unless the measured benefit justifies its cost.
- Agent/model wall time is queue/model/provider dependent. Wave B compares dispatch semantics and unnecessary delegation rather than treating one LLM sample as a stable latency benchmark.
- Skill disclosure changes require a before/after payload measurement and explicit behavior tests; token reduction alone is not sufficient.
- No public MCP tool-count or contract-epoch change is permitted.
