## alpha.8 — bounded generic Page Assist

- spec: [`v1.0-alpha8-page-assist.md`](./v1.0-alpha8-page-assist.md).
- implementation branch: `feat/v1.0-extension-page-assist-alpha8-20260907`, based on Alpha 6 HEAD `91fb8cdcc70d2d5b63c29c4423efb68c1fb0c433` and developed in parallel with Alpha 7 Grok.
- current state: Page Assist is default-off and exposes only `inspect` / `click` / `fill` on explicitly user-approved origins. Inspection returns bounded visible text plus ephemeral opaque refs; successful mutation invalidates the generation. Selectors/XPath/JS/CDP/cookies/storage, sensitive password/file/OTP/payment-card fields, cross-origin iframe traversal, and mutation reinjection/retry are excluded.
- authority model: remote access extends the existing OAuth Connector grant record with exact `(connector_id, grant_generation, device_id, endpoint_ref)` Page Assist authority. Grant mutation is enrolled-owner-device only and addresses the exact Connector instance. Edge first filters by the authenticated Connector generation and then by the explicit routed device; sibling Connectors sharing one public `client_id` cannot inherit each other's browser authority, and client-only legacy identity gets none. Link carries the reduced endpoint grant only through trusted Unix IPC with a runtime-generation fence, while local exact-origin Extension permission remains an independent required gate.
- targeted verification: Page Assist core/content/Options 20/20 PASS; background bind PASS; extension smoke PASS; focused Edge authority/store/routing 67/67 PASS; focused Rust CLI/runtime/HTTP/Link authority tests PASS.
- full local qualification: `cargo fmt --check`, clippy with `-D warnings`, `cargo test --workspace` (957 unit + 1 guardian + 4 TCC), `scripts/release-gate.sh node` (root Node 514/514 plus Edge/extension lanes), `scripts/release-gate.sh hygiene`, and `git diff --check` all pass.
- integration boundary: this Alpha 6-based branch still must not deploy its Edge bundle while v0.4.8 Connector work is active. The current v0.4.8 exact Connector identity (`connector_id + grant_generation`) has been ported into the Alpha 8 browser-authority slice and its combined targeted Connector/Edge regressions are green. Production UAT still requires a production-compatible candidate after the maintenance line stabilizes. No production deployment, runtime activation, merge, tag, or release is part of Alpha 8.
