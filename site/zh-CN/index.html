herdr-mcp

一个精简的 MCP 网关，让 ChatGPT 及其它远程规划器能在 Herdr 工作站上检查、编辑、运行与委派任务，而无需直接暴露工作站。

稳定的公共边界

OAuth、MCP 传输与公共契约都位于边缘层。工作站只会发起带认证的出站连接，不存在暴露的公网入站端口。

直接下手优先

远程规划器可获得一等公民的 fs、patch、Git、image 与 shell 工具。只有推理或并行调研值得付出成本时，才使用廉价的本地开发 agent。

Runtime A/B

新的本地 Runtime 代际会针对冻结的工具契约进行验证，原子切换、排空并在同一 Link 与 Connector 后回滚。Runtime 发布与 Edge 发布是相互独立的平面。

自我维护

项目 skill 描述工具顺序、变更纪律、agent 分发偏好与受监督的自升级路径。Runtime 发布与 Edge 发布保持独立。

浏览器唤醒通道

MV3 扩展只与本机 localhost 通信，可把 agent 的进度或完成状态回推到绑定的 Web 会话，而无需把本地令牌经过 Cloudflare。

开源友好

workers.dev 是默认的公共源站。如需长期稳定的 OAuth/MCP 身份，可选配 Custom Domain；遗留 Tunnel 仅作迁移用途。
