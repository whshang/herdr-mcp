让 ChatGPT 真正接上你的开发机。

不用先学架构，也不用自己拼部署命令。把一条安装提示词交给 Cursor、Codex、Claude Code 等本地 Coding Agent；它会安装 Herdr 和 herdr-mcp、部署 Edge 与 Link，只在 Cloudflare 和 ChatGPT 必须由你本人操作时暂停。

1. 复制一句话

把安装指引 URL 发给你已经在用的 Coding Agent。Herdr 缺失时也由 Agent 按官方 stable 安装器处理。

复制安装提示词 →

2. 只操作两次

第一次是 Cloudflare 登录 / API Token；第二次是在 ChatGPT 添加 herdr Connector 并完成 OAuth。其余步骤自动执行并验证。

3. 发第一条真实任务

安装完成后，新开 ChatGPT 会话并发送“分析我的 Herdr 里有哪些项目。只读，不要修改。”，验证真实工作站是否已连通。

浏览器扩展是可选项

基础 Connector 可用后，再从 Chrome Web Store 安装 Herdr 扩展，用于浏览器控制中心、workspace binding、长对话连续工作和“排队”下一轮消息。在已绑定 ChatGPT Project 里手动新开会话后，直接说“继续”即可；Herdr 会搜索 durable continuity，只有稳定身份唯一匹配才自动恢复，否则要求确认。普通用户不走 Developer mode / Load unpacked。
