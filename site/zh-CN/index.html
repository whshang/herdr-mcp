Web AI 负责思考 · Herdr 保留现场 · herdr-mcp 打通两端

让 ChatGPT 真正接上你的开发机。

herdr-mcp 是 Web AI 与本地 Herdr 工作站之间的远程开发控制面。ChatGPT 可以直接读改代码、查看 Git、运行 Shell、观察持久工作区，并在需要独立推理时调度本地 Agent；代码和真实执行仍留在自己的机器上。

Web 模型，拥有本机的手和眼睛

确定性工作直接用文件、搜索、Patch、Git 和 Shell 工具完成，不必把每一步都转交给另一个 Agent。网页模型可以一直掌握目标、取舍和验收。

Herdr 保存真正的工作现场

workspace、pane、PTY 和 Agent 不依赖某一次网页请求存在。长测试、服务器、并行 Agent 都有稳定身份，新的网页回合回来后可以重新观察并继续。

需要第二份推理时再调度 Agent

独立调查、并行实现、代码审查可以交给 Pi、Grok 等 Herdr Agent。读文件、看 Git、跑测试则直接做，减少转述、延迟和上下文消耗。

浏览器连续工作

MCP 负责 Web AI → 工作站；浏览器扩展补上工作站 → Web 会话。Agent 完成、回复卡住或对话过长时，可以按安全状态机继续、恢复或接力。

工作站不用暴露公网端口

Cloudflare Edge 提供稳定 OAuth/MCP 入口，工作站主动建立认证 WSS。ChatGPT 不需要本机 bearer，公网身份和本地执行环境彼此解耦。

本机 Runtime 可以独立升级

Runtime A/B 在同一公开契约内验证 candidate、切换、drain 和 rollback。公网 Connector URL 保持稳定，不需要因为普通本机修复反复重连 ChatGPT。
