系统拓扑

本机零公网入站端口，按需闭合浏览器双向回路

所有开发机主动向你自己的 Cloudflare Worker 发起出站加密连接，无需公网 IP 或端口映射。

职责边界清晰：Web AI 负责规划；Cloudflare 提供稳定公网 OAuth / MCP 入口与多设备路由；herdr-mcp 执行确定性访问边界；Herdr TUI 持久保有现场；扩展按需提供浏览器控制中心（Browser Control Center）、排队下一轮与跨会话接力。
