思考はブラウザのまま、実作業はあなたのマシン上で。

Herdr-MCP は ChatGPT・Claude・Grok などの Web AI に実ファイル、Git、端末、ローカル Coding Agent への安全なアクセスを提供し、Herdr が会話やデバイスを跨いで開発現場を維持します。

システム構成

受信ポート非公開の中核経路と、任意のブラウザ双方向ループ

各ワークステーションから自分の Cloudflare Worker へ外向き WSS 接続を張るため、ポート開放は不要です。

明確な責務分離：Web AI が計画し、Cloudflare が公開 OAuth / MCP とデバイスルーティングを担い、herdr-mcp が境界を強制し、Herdr TUI が現場を保持し、拡張が Browser Control Center・次ターン予約・引き継ぎを追加します。

v1.1 の主な機能

継続的な開発を支える 6 つの基盤

永続性

会話を閉じても現場は続く

Herdr TUI の workspace、PTY 端末、サーバー、Agent はタブを閉じても動き続け、別の会話やマシンから再開できます。

マルチマシン

1 つの Worker で複数台を制御

無料の Cloudflare Workers Free に macOS・Linux・Windows を登録し、明示的な device_id でルーティングします。

並列 Agent

18 個の直接ツール + 任意の Agent

小さな変更は直接実行し、大きなタスクは Codex・Claude Code・Pi・Cline・OpenCode 等へ並列委譲します。

WebChat 1.1

マルチ WebChat 制御と引き継ぎ

ChatGPT・Claude・Grok セッションの作成・継続・停止・引き継ぎと Doubao 画像生成をアカウント分離付きで制御します。

アダプター 1.1

Browser Control Center と BrowserPage

サイドパネル制御、次ターン予約、ID 不要の引き継ぎ、世代フェンス付きタブ操作、再利用可能なブラウザスキル。

安全性

明示的配信状態と署名検証更新
