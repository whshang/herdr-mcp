Product boundaries stay explicit. Web AI plans. Cloudflare exposes a stable public MCP/OAuth endpoint. herdr-mcp enforces workstation access. Herdr owns persistent runtime state. The extension adds a return path only when browser continuity is useful.

Reasoning

Reuse the Web AI you already have

Keep ChatGPT as the primary planning surface instead of forcing every task through another local model or agent loop.

Persistence

The worksite survives the chat

Repositories, worktrees, terminals, servers, and agents keep running even when a conversation ends or another device takes over.

Parallelism

Direct tools when small, agents when useful

Read, patch, Git, and test directly. Delegate independent or long-running work to replaceable local coding agents.

Architecture landscape

Why Herdr-MCP when coding MCPs, remote workers, tmux, ACP, and Codex bridges already exist?

They optimize different entry points and state models. Herdr-MCP focuses on Web-first planning plus a persistent, observable, human-takeover-friendly workstation.
