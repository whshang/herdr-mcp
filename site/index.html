Web AI reasons · Herdr keeps the workspace · herdr-mcp connects both sides

Connect ChatGPT to the real development machine.

herdr-mcp is a remote development control plane between Web AI and a local Herdr workstation. ChatGPT can read and edit code, inspect Git, run shell commands, observe persistent workspaces, and delegate to local agents when independent reasoning is useful—while code and execution stay on your machine.

Give Web AI local hands and eyes

Deterministic work uses first-class file, search, patch, Git and shell tools directly. The Web model can keep ownership of goals, trade-offs and verification instead of routing every action through another agent.

Herdr keeps the real workspace alive

Workspaces, panes, PTYs and agents outlive individual browser requests. Long tests, servers and parallel agents keep stable identities that later turns can inspect again.

Delegate only when another reasoning process helps

Focused investigation, parallel implementation and review can go to Herdr agents such as Pi or Grok. Reading files, checking Git and running tests remain direct operations.

The browser extension closes the working loop

Continuity sends progress and recovery back to the right conversation; Browser Control Center shows live workspaces and explicit pane targets in Chrome Side Panel; Queue saves the next ChatGPT instruction without interrupting the current reply.

No public inbound workstation port

Cloudflare Edge provides the stable OAuth/MCP origin while the workstation creates an authenticated outbound WSS link. ChatGPT never needs the local bearer.

Upgrade the local runtime independently

Runtime A/B validates candidates, switches traffic, drains old generations and supports rollback within the same public contract—without changing the Connector URL.
