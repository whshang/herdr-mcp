herdr-mcp

A lean MCP gateway that lets ChatGPT and other remote planners inspect, edit, run, and delegate on a Herdr workstation without exposing the workstation directly.

Stable public boundary

OAuth, MCP transport and the public contract live at the Edge. The workstation makes an outbound authenticated connection; there is no public inbound workstation port.

Direct work first

Remote planners get first-class fs, patch, Git, image and shell tools. Cheap local development agents are used only when reasoning or parallel investigation is worth the cost.

Runtime A/B

New local runtime generations are validated against the frozen tool contract, switched atomically, drained and rolled back behind the same Link and Connector.

Self-maintaining

The project skill describes tool order, mutation discipline, agent dispatch preferences and the supervised self-update path. Runtime releases and Edge releases remain separate planes.

Browser wake channel

The MV3 extension talks only to localhost and can push agent progress or completion back into the bound web conversation without sending the local token through Cloudflare.

Open-source friendly

workers.dev is the default public origin. A Custom Domain is optional for a long-lived stable OAuth/MCP identity; legacy Tunnel is migration-only.
