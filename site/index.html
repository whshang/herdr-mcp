Give ChatGPT real access to your development machine.

You do not need to learn the architecture or assemble deployment commands first. Give one setup prompt to Cursor, Codex, Claude Code, or another local coding agent. It installs Herdr and herdr-mcp, deploys Edge and Link, and pauses only for Cloudflare and ChatGPT steps that require you.

1. Copy one prompt

Give the install guide URL to the coding agent you already use. If Herdr is missing, the agent installs the official stable build too.

Copy the setup prompt →

2. Do only two human steps

First: Cloudflare sign-in / API Token. Second: add the herdr Connector in ChatGPT and complete OAuth. The agent automates and verifies everything else.

3. Run one real task

Open a new ChatGPT conversation and ask it to inspect your Herdr projects read-only. That proves the public path reaches the real workstation.

v0.4.2: images and temporary artifacts

Read local images directly through MCP, import transferable signed HTTPS artifacts without a relay, and use the private R2 artifact relay only when a temporary cross-boundary handoff is useful. R2 is provisioned during setup but is not a permanent asset library.

The browser extension is optional

After the base Connector works, install the Herdr extension for Browser Control Center, workspace binding, continuity, queued next-turn messages, and the optional Thin Web Bridge. The bridge forwards signed URL metadata only; coding continues normally when it is absent.

Go deeper only when needed

A normal install does not require understanding MCP epochs, Runtime A/B, Worker internals, or GA evidence. Read those pages only for troubleshooting or herdr-mcp development.
