System Topology

Inbound-closed core plane, optional two-way browser loop

Your workstations never open inbound ports: each machine dials outbound WSS to your own Cloudflare Worker.

Explicit boundaries: Web AI plans, Cloudflare coordinates public OAuth & device routing, herdr-mcp enforces deterministic workstation tools, Herdr TUI preserves live state, and the extension closes the loop for Browser Control Center, queued turns, and handoff.
